# IQuit — мини-приложение Telegram

Тренировка интеллекта: тест по 6 темам → алгоритм находит слабые зоны →
теория + практика под завалы → цикл. Плюс ударный режим и рейтинг друзей.

## Что уже готово (работает сейчас)

- Полный флоу: тест → анализ завалов → теория → практика → новый тест.
- 6 тем (математика, логика, вербальные, пространство, память, внимание), 62+ вопросов.
- Картинки GigaChat в стиле воксель + 2D-мультяшный, только SVG-иконки.
- Ударный режим, рейтинг, профиль, история.
- Сохранение прогресса в **Telegram CloudStorage** (на серверах Telegram, привязано к пользователю).
- `AIAdapter` в `algorithm.js` — готов к подключению будущего API-ИИ.

## Как запустить в Telegram (пошагово)

### 1. Создать бота
1. В Telegram открой **@BotFather**.
2. Команда `/newbot`, задай имя и username (например `IQuitBrainBot`).
3. BotFather вернёт **токен** (вида `123456:ABC...`) — сохрани его, понадобится позже.

### 2. Включить BotFather → Menu Button
В @BotFather отправь `/setmenubutton`, выбери своего бота, укажи адрес будущего
хостинга (см. шаг 4) — туда будут смотреть все экранные кнопки.

### 3. Настроить мини-апп (WebApp)
Через @BotFather `/mybots` → своего бота → **Bot Settings → Domain**:
укажи домен хостинга. После этого мини-апп станет доступен по кнопке
WebApp/`t.me/<username>?startapp`.

### 4. Загрузить файлы на хостинг
`index.html`, `style.css`, `app.js`, `data.js`, `algorithm.js` и папку `assets/`
(картинки) нужно отдать по HTTPS на любой статический хостинг, доступный из
Telegram (например Vercel, Netlify, Cloudflare Pages, или свой сервер).

> Важно: домен, указанный в BotFather (шаг 3), должен совпадать с адресом,
> по которому лежит `index.html`.

### 5. Проверить
1. Открой бота в Telegram → кнопка мини-аппа (или ссылка `?startapp`).
2. При первом запуске попросится разрешение — согласись.
3. Данные пользователя появятся в `telem.initData`, прогресс — в CloudStorage
   (не в localStorage, который используется только вне Telegram как фолбэк).

## Примечания

- **CloudStorage** — максимум ~4096 байт на ключ. Мы храним 3 ключа
  (`iquit_state`, `iquit_friends`, `iquit_history`) — state лучше не раздувать.
- **Рейтинг друзей «по-настоящему»** требует общего хранилища (сервер+БД или
  бот как прокси), т.к. CloudStorage у каждого игрока свой. Сейчас друзья
  хранятся локально — для MVP; реальный общий рейтинг — следующий этап.
- **ИИ-генерация вопросов**: локальная Ollama на этом ПК (4 ядра CPU, без GPU)
  слишком медленная и выдаёт некорректные ответы. Основа — рукописный пул
  (ротация + шаблоны). Для живого ИИ нужен облачный API-ключ (VseGPT, YandexGPT
  и т.п.) — адаптер `algorithm.js → IQAI.adapter` под это готов.

## Локальный просмотр (без Telegram)

```bash
cd IQuit
python3 -m http.server 8090
# открыть http://localhost:8090
```
Вне Telegram данные сохраняются в localStorage (фолбэк), Telegram SDK не грузится.
